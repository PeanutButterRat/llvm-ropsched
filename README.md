# llvm-ropsched

**llvm-ropsched** is a fork of the LLVM project that was used to research the affects of instruction-scheduling on **return-oriented programming (ROP)** attacks. For more information, please check out the parent repository, [RopSched][RopSched].

## Usage
Please see the original [LLVM repository][LLVM] for usage information.
